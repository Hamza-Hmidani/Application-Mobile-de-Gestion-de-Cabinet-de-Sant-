# 🏥 Application Mobile de Gestion de Cabinet de Santé

Une application mobile développée avec **Java** sous **Android Studio** permettant de faciliter la gestion d'un cabinet médical. Cette application aide les médecins et le personnel administratif à gérer les patients, les rendez-vous et les dossiers médicaux de manière simple et efficace.

---

## 📱 Fonctionnalités

### 👤 Gestion des utilisateurs
- Authentification sécurisée
- Connexion et déconnexion
- Gestion des profils

### 🩺 Gestion des patients
- Ajouter un patient
- Modifier les informations d'un patient
- Supprimer un patient
- Consulter la liste des patients
- Rechercher un patient

### 📅 Gestion des rendez-vous
- Ajouter un rendez-vous
- Modifier un rendez-vous
- Annuler un rendez-vous
- Consulter le calendrier des rendez-vous

### 📋 Dossiers médicaux
- Création d'un dossier médical
- Consultation de l'historique médical
- Mise à jour des informations médicales

### 💊 Gestion des consultations
- Enregistrement des consultations
- Ajout d'ordonnances
- Notes du médecin

## 🗄 Base de données

L'application utilise **SQLite** pour stocker localement les données.

Les principales tables sont :

- Users
- Patients
- Appointments
- MedicalRecords
- Consultations

---

## 🚀 Installation

1. Cloner le dépôt

```bash
git clone https://github.com/votre-utilisateur/cabinet-sante.git
```

2. Ouvrir le projet avec Android Studio.

3. Synchroniser Gradle.

4. Exécuter l'application sur un émulateur ou un appareil Android.
