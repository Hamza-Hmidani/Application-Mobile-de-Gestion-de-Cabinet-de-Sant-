# 🚗 Android Car Rental Application

A modern Android application for managing vehicle rentals. The application allows users to browse available cars, authenticate securely, make reservations, and manage their rental history. It was developed using Java and Android Studio following object-oriented programming principles.

---

## 📱 Features

- 🔐 User Authentication (Login & Registration)
- 🚘 Browse Available Cars
- 🔍 View Car Details
- 📅 Book a Vehicle
- ❤️ Add Cars to Favorites
- 👤 User Profile Management
- 📜 Rental History
- 💾 Local Data Storage with SQLite
- 🎨 Clean and Responsive User Interface

---

## 🛠️ Technologies Used

- Java
- Android Studio
- SQLite
- XML
- Material Design Components

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/Android-Car-Rental-Application.git
```

2. Open the project in **Android Studio**.

3. Wait for Gradle synchronization.

4. Build and run the application on an emulator or Android device.

---

## 💾 Database

The application uses **SQLite** as its local database.

Main entities include:

- Users
- Cars
- Reservations
- Favorites
